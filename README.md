# CareBilling

CareBilling is a Nextcloud application for invoice and billing management.

The application provides customer, service, invoice, payment, and reporting
functionality, with optional integration with CareForms.

## Project Status

CareBilling is currently under active development.

## Planned Features

- Customer management
- Service and pricing catalog
- Invoice creation and management
- Invoice PDF generation
- Payment tracking
- Outstanding and overdue invoice tracking
- Reporting
- Audit logging
- Optional CareForms integration

## Integration

CareBilling is designed as a standalone Nextcloud application.

When CareForms is installed, CareBilling will optionally be able to import
relevant patient and service data while maintaining independent financial
records.
